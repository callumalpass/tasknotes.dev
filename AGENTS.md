# TaskNotes documentation

This repository owns public authored TaskNotes documentation and assets.

- Keep app and Obsidian instructions explicitly scoped.
- Use `collection` for shared and app concepts; reserve `vault`, `Base`, and
  `command palette` for Obsidian pages.
- Do not copy release notes, generated references, or the formal specification
  into authored content. They are imported from their owning repositories.
- Update `navigation.yml` when a new public page should appear in navigation.
- Preserve public URLs through `redirects.yml` when moving pages.
- Run `npm test` after changing content, navigation, redirects, or rendering.
