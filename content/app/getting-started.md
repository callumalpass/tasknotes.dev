# Get started with the TaskNotes app

TaskNotes app is currently in beta. Features, availability, and setup steps may
change before the stable release.

The app supports TaskNotes v5 collections based on the mdbase 0.3.0
specification.

## 1. Open TaskNotes

Use [app.tasknotes.dev](https://app.tasknotes.dev/) in a supported browser, or
install TaskNotes from the
[App Store](https://apps.apple.com/app/tasknotes/id6797168033) or
[Google Play](https://play.google.com/store/apps/details?id=dev.tasknotes.app).
The web and native applications use the same task interface.

On the web you can try TaskNotes without an account: it opens a collection
saved only in that browser.

## 2. Choose a collection

TaskNotes opens every collection through mdbase. Sign in, then create a new
collection or choose one you already have. To use a folder on your computer,
such as an Obsidian vault, sync it with the mdbase Connect desktop app first.
Read [What is mdbase?](/app/mdbase/) if this is new to you, then
[Choose a collection](/app/collections/) to compare the options.

Follow [Connect TaskNotes to mdbase](/app/connect-mdbase/) for the steps.

## 3. Create a task

Use **Add task**, enter a title, and save. Capture understands the collection's
configured status, priority, project, context, and tag values.

For a worked example, [create a task and find its Markdown file](/guides/markdown-todo/).

## 4. Review the starter views

Open **Today** for current work, **Upcoming** for scheduled tasks, and **Views**
for the complete collection of lists, boards, calendars, and project views.
Navigation belongs to the current collection and can be reordered from Views.

## 5. Check collection status

Open **Settings** to see the collection location, connection state, last refresh,
notification access, task model settings, and appearance preference.
