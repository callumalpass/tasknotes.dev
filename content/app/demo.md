# Interactive demo

Explore the TaskNotes app using a disposable collection of sample tasks. You
can complete and edit tasks, use Scratchpad, search, and move between views
without signing in or connecting a collection.

The demo keeps changes only for the current session. Reloading or resetting it
starts again with the original sample data.
